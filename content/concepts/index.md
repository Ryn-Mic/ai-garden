# 🧠 核心概念

底层节点。这些笔记之间的关系最密，也是别的笔记最常引用的地方。

## 模型基础

- [[大语言模型]] — 一切的地基
- [[Transformer]] — 当前所有主流模型的骨架
- [[Embedding]] — 把语义变成向量

## 能力放大

- [[提示工程]] — 最便宜的能力杠杆
- [[上下文工程]] — 给模型喂对信息
- [[RAG]] — 让模型说外部知识
- [[微调]] — 把知识刻进权重
- [[向量数据库]] — RAG 的检索底座

## 走向行动

- [[Agent]] — 让模型自己调工具、做决策
- [[MCP]] — Agent 接入外部世界的标准插口

## 关系图

- [[大语言模型]] → [[Transformer]] → [[Embedding]] → [[向量数据库]]
- [[上下文工程]] → [[RAG]] → [[向量数据库]]
- [[提示工程]] → [[Agent]] → [[MCP]]
- 选型岔路：[[RAG与微调]]
