# 大语言模型

> [!info] 阅读定位
> **进阶研究 · 技术研究**。模型机制笔记；第一次使用先看 [[tutorials/basics/通用Agent的使用|通用Agent的使用]]。

> [!abstract] 一句话定义
> 通过大规模数据学习语言规律与任务能力的模型。预测下一个 token 是常见的预训练目标；实际模型还可能经历指令微调、偏好优化等训练，不能把全部行为归因于一个目标。

## 为什么重要

它是许多 AI 应用的基础。[[concepts/Transformer|Transformer]]、训练目标和后训练过程帮助理解模型能力；产品行为还受上下文、工具和应用策略影响，不能只靠架构解释。

## 核心原理

<iframe src="llm-inference.html" width="100%" height="700" frameborder="0"></iframe>

```text
输入文本 → 分词(tokenize) → 向量化([[concepts/Embedding|Embedding]]) → [[concepts/Transformer|Transformer]] 堆叠 → 概率分布 → 采样出下一个 token
```

三个关键事实：

1. **生成能力不等于事实保证**。模型可以回答事实问题，但输出仍需证据核对；训练数据、推理、上下文和工具结果都可能影响错误，不能把幻觉归因于单一因素。
2. **上下文窗口有限**。装不下的信息必须靠 [[concepts/RAG|RAG]] 或 [[concepts/上下文工程|上下文工程]] 解决。
3. **权重里的是模式，不是可检索的知识**。想稳定注入新知识，见 [[concepts/微调|微调]] 与 [[research/comparisons/RAG与微调|RAG与微调]]。

## 关键术语

| 术语 | 含义 |
| --- | --- |
| Token | 模型的最小处理单位，约等于 0.75 个英文单词 / 1–2 个汉字 |
| 上下文窗口 | 单次推理能看到的 token 上限 |
| 参数 | 权重数量，决定容量与成本 |
| 温度 | 采样随机性，越高越发散 |
| 预训练 / 后训练 | 学语言模式 / 学听指令与对齐 |
| 幻觉 | 流畅但错误的输出，是概率模型的固有属性 |

## 能力边界

**擅长**：改写、总结、翻译、代码、结构化抽取、按模式生成。

**不可靠**：精确计算、最新事实、长链条严格推理、需要引用的断言。

> [!warning] 常见误解
> 「模型知道 X」通常意味着「模型能流畅地说出很像 X 的话」。两者在关键场景必须区分——这也是 [[concepts/RAG|RAG]] 存在的理由。
