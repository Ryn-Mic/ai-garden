# 大语言模型

> [!abstract] 一句话定义
> 用海量文本训练出的、以「预测下一个 token」为唯一目标的神经网络。所有看似智能的行为，都是这个目标的副产品。

## 为什么重要

它是这一轮 AI 浪潮的地基。理解 [[Transformer]] 的架构 + 「下一个 token 预测」这个训练目标，就能解释大部分模型行为——包括幻觉。

## 核心原理

```text
输入文本 → 分词(tokenize) → 向量化([[Embedding]]) → [[Transformer]] 堆叠 → 概率分布 → 采样出下一个 token
```

三个关键事实：

1. **它是概率模型，不是数据库**。它给的是「最像人话的续写」，不是「事实查询」。这就是幻觉的根源。
2. **上下文窗口有限**。装不下的信息必须靠 [[RAG]] 或 [[上下文工程]] 解决。
3. **权重里的是模式，不是可检索的知识**。想稳定注入新知识，见 [[微调]] 与 [[RAG与微调]]。

## 关键术语

| 术语 | 含义 |
| --- | --- |
| Token | 模型的最小处理单位，约等于 0.75 个英文单词 / 1–2 个汉字 |
| 上下文窗口 | 单次推理能看到的 token 上限 |
| 参数 | 权重数量，决定容量与成本 |
| 温度 | 采样随机性，越高越发散 |
| 预训练 / 后训练 | 学语言模式 / 学听指令与对齐 |
| 幻觉 | 流畅但错误的输出，是概率模型的固有属性 |

## 能力边界

**擅长**：改写、总结、翻译、代码、结构化抽取、按模式生成。

**不可靠**：精确计算、最新事实、长链条严格推理、需要引用的断言。

> [!warning] 常见误解
> 「模型知道 X」通常意味着「模型能流畅地说出很像 X 的话」。两者在关键场景必须区分——这也是 [[RAG]] 存在的理由。
