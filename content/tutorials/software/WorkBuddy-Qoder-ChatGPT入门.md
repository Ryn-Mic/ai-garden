# WorkBuddy、Qoder、ChatGPT：同一个任务怎么开始

> [!info] 阅读定位
> **上手指南 · 入门**。只读你正在用的产品小节。练习约 10～15 分钟，不需要接邮箱、装 MCP 或写代码。

**目标**：在现成软件里完成会议记录整理，而不是自己搭建应用。

**资料依据**：WorkBuddy、Qoder 的流程按官方文档整理；本机另观察了 WorkBuddy 5.6.2 的主菜单。ChatGPT 部分采用普通聊天练习，不依赖特定付费功能。**菜单观察不等于任务实测**：三部分均未完成账户内逐步验证，功能可能随版本、地区或账户变化。

## 先准备同一份练习材料

打开 [[tutorials/basics/通用Agent的使用#第 2 步：把目标、材料、验收要求一起发给它|会议记录练习]]，复制完整的任务和虚构材料。

先用粘贴文字的方式，排除文件权限和格式转换的干扰。**第一次用顺手，比第一次就装齐插件更重要。**

需要文件练习时，使用 [[tutorials/basics/练习材料与验收|虚构练习包]]；里面有原始材料、工作说明和独立验收清单。

## WorkBuddy：从一个新任务开始

适用：WorkBuddy 桌面工作台，不是 CodeBuddy 的编码产品界面。

![[assets/guides/workbuddy-5.6.2-navigation.png|WorkBuddy 5.6.2 主菜单，截图仅保留导航区域]]

**本机菜单观察（2026-09-30）**：左侧有「新建任务」和「专家·技能·连接器」。截图已裁去会话、任务列表和账户区域；只证明这些主菜单在 5.6.2 中存在，未核对技能子页面或执行完整任务。

### 1. 打开新任务输入区

在工作台左侧选择「新建任务」。5.6.2 主菜单可见这个入口；官方文档把流程称为“Create Task / 创建任务”。打开后的具体界面按当前版本核对。

**确认**：你正在输入一个新任务，而不是继续一个无关的旧任务。

### 2. 粘贴完整的练习

先只提供文字。官方还支持上传或拖入文件、粘贴截图，以及用 `@` 引用上下文；这些等文字练习成功后再用。

**确认**：输入区里同时有任务要求和原始会议记录，而不是只有“帮我整理”。

### 3. 提交后查看进度与结果

官方文档说明：对话区展示执行步骤和输出，右侧展示文件、产物或预览。

这次只需要表格输出；如果应用请求连接外部服务或扩大文件访问范围，先取消不必要的授权。文本中的禁止语句不能替代权限设置。

**确认**：看到两条已安排任务和单独的待确认事项，而不是只看到“任务已完成”。

### 4. 对照原文验收

按 [[tutorials/basics/通用Agent的使用#第 3 步：对照原文检查结果|验收清单]] 检查日期和负责人。出错时继续发送明确的字段修正，不要笼统要求“再专业一点”。

**完成标准**：事实与原文一致。需要安装 Skill 时，再看 [[tutorials/skills/Skill从加载到验证#WorkBuddy：从技能市场安装|WorkBuddy 技能市场流程]]。

## Qoder：选择适合日常任务的形态

适用：当前官方文档中的 **Qoder 桌面应用**。Qoder IDE、CLI、QoderWork 与桌面应用的界面和功能不能直接混用。

### 1. 新建任务，选择 General / 通用模式

官方文档区分 Coding（编码）与 General（通用）。资料整理、研究与内容任务先选择 General，不需要创建 Git 分支或开发项目。

**确认**：任务围绕日常资料或文件夹，而不是要求你先初始化代码仓库。若你的界面没有该模式，先核对产品形态，不要照抄桌面应用按钮路径。

### 2. 只提供练习所需的文字

粘贴完整练习。如果当前流程需要关联文件夹，使用单独的测试文件夹，不选择整个桌面或公司资料根目录。

**确认**：本次输入和授权范围只有练习所需内容。

### 3. 提交任务并查看输出

不需要为这个练习安装扩展。若出现访问审批，逐项看它要读什么、执行什么；拒绝与文字整理无关的动作。

**确认**：交付物是可核对的表格；不是一段无法追溯的总结。

### 4. 核对缺失字段

小陈的截止日期应该是“待确认”。反复失败时，用新任务重新提供短材料，区分资料问题与长对话干扰。

**完成标准**：通过原文验收。后续通过 Extensions → Skills 安装或导入 Skill，见 [[tutorials/skills/Skill从加载到验证#Qoder：安装或导入|Qoder Skill 流程]]。

## ChatGPT：普通聊天就能做的练习

适用：可以发送文字的普通聊天界面。不要求 Projects、GPTs、连接器、Agent 模式或某个订阅档位。

### 1. 新建一个聊天

为练习单独建立聊天，避免混入之前的工作资料。

**确认**：输入区准备接收新任务；没有必要要求它读取电脑文件夹。

### 2. 粘贴要求与原文

发送完整练习。只给文件名、只发一个链接，不能替代本次需要的正文材料。

**确认**：消息中能看到会议记录本身。

### 3. 等待结果并逐项核对

检查表头、负责人、缺失日期与投放广告的状态。不要因为答案流畅就省掉原文核对。

**确认**：没有给小陈补造日期，也没有把讨论变成既定决策。

### 4. 保存经验证的工作说明

把稳定的要求保存为自己的提示模板，下次开新聊天时一起粘贴。若要用项目说明等持久功能，先查自己账户当前的官方帮助与设置。

**完成标准**：模板加材料能重复得到可验收结果。**本教程不假设普通聊天支持直接安装 `SKILL.md`**；粘贴工作说明不等于原生 Skill 安装。

## 三个产品不要互相照搬什么

| 可以复用 | 不应直接照搬 |
| --- | --- |
| 目标、原始资料、输出样例、验收清单 | 菜单路径、安装目录、文件授权方式 |
| 自己整理的工作说明 | 是否支持原生 Skill、MCP、项目记忆 |
| 先测试再扩大权限的原则 | 账户权限、付费功能和地区可用性 |

如果最简单的文字任务已经能做，不必为了“更像 Agent”换软件或增加工具。
