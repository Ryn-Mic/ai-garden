# 通用Agent的使用

> [!abstract] 边界声明
> 这篇只讲**通用 Agent（General-Purpose Agent）**：帮你查资料、读网页、整理文档、串起日常自动化流程的那类 Agent。
>
> 专写代码的**编码 Agent**（[[Cursor]]、[[Claude-Code|Claude Code]] 等）是另一个物种——它们靠代码仓库索引、语法树分析、终端执行吃饭，工具链和用法完全不同，不在本篇范围。

**前置知识**：[[Agent]]、[[提示工程]]
**预计耗时**：20 分钟（读完即可上手，不含动手搭建时间）

---

## 读完你能做到什么

- 分清"通用 Agent"和"编码 Agent"，知道各自解决什么问题
- 用无代码平台（[[Dify]]、扣子 Coze）搭一个能查资料、读网页、出简报的研究助理
- 看懂 Agent 的执行过程，知道什么时候该出手干预
- 掌握一条安全底线，不让 Agent 闯祸

---

## 一、什么是通用 Agent？

先建立正确的心智模型。

裸的大语言模型像一个**高智商但断网的实习生**：能推理、会写文章，但它不知道今天几号，看不到你的文件，更碰不到你的邮箱。你问它上周的行业新闻，它只能靠训练时的旧记忆——甚至开始编。

**通用 Agent 给这个实习生接上了"感知"和"手脚"**：

- **感知**：搜索引擎（能看外面的世界）、网页抓取器（能翻开网页读正文）、文档阅读器（能读你上传的资料）；
- **手脚**：写表格、发邮件、存文件、建日程——真正产生动作；
- **循环**：也是最关键的一点，它不是"一步做完"，而是像 [[Agent]] 里说的那样，反复地"想一步、做一步、看一眼结果"，自己决定先查什么、再读什么、什么时候收工。

### 看一段真实的工作过程

你对它说："整理一下新能源汽车的最新补贴政策，生成报告。"

它内部大概是这样的：

1. **想**：「我的知识过时了，先搜最新政策。」
2. **做**：搜索"2025 新能源汽车补贴政策"，拿到 5 个链接和摘要。
3. **看**：「摘要提到核心条款在两份文件里，摘要不够细。」
4. **想**：「把这两篇的正文抓下来。」
5. **做**：抓取两个网页的正文，读到完整条款。
6. **想**：「信息齐了，收工，按用户要的格式写报告。」
7. **交付**：一份带来源链接的 Markdown 报告。

注意最后一点——**靠谱的 Agent 会附上它参考过的链接**。这既是给你的验收凭证，也是它区别于"张口就编"的裸模型的关键特征。

## 二、使用三步法

无论你用的是网页版 Agent（如带搜索功能的 Claude/ChatGPT）、无代码平台（[[Dify]]、扣子），还是本地客户端，用好通用 Agent 都可以归结为三步。

### 第 1 步：把任务说清楚

通用 Agent 翻车，**大多数时候不是能力不够，而是需求没说清**。它拿到模糊指令后会自己猜，猜错方向就把搜索预算全烧光。

对比一下：

```markdown
❌ 坏指令："帮我调研一下 AI 手机市场。"
   —— 方向不明、边界不明、产出不明，Agent 只能瞎逛。

✅ 好指令：
# 目标
调研近半年苹果、华为、荣耀在"AI 手机"上的核心卖点。

# 范围与约束
1. 只看官方发布会和主流媒体评测，排除小道传闻。
2. 重点对比端侧模型参数和独占功能。
3. 搜索不超过 5 轮。

# 输出格式
Markdown 对比表格（品牌 / 机型 / 核心特性 / 来源链接），
文末附 300 字趋势总结。
```

四要素：**目标、边界、步数上限、交付格式**。这就像给实习生布置任务——不写验收标准，你就没资格抱怨交付质量。

### 第 2 步：装配工具箱

Agent 的能力上限由工具决定，但**工具不是越多越好**。三条原则：

1. **少而精**：3～5 个、互不重叠。工具一多，模型就犯选择困难，甚至重复调用两个功能相似的搜索。
2. **最小权限**：探索新任务时，绝不要预先挂上"有后果"的工具（自动发邮件、删文件、支付扣款）。先让它只带"眼睛"（搜索、阅读），跑通了再谈"手脚"。
3. **描述写清楚**：工具描述就是模型看的使用说明书，写法见 [[Agent]] 的工具一节。

### 第 3 步：盯着它干活

用 Agent 不是"发完指令就走人"，而是像 code review 一样**读它的执行轨迹（Trace）**——每一步在想什么、调了什么工具、返回了什么。

重点盯三处：

- **方向**：搜索关键词有没有跑偏？比如你问"小米 SU7"，它搜成了小米手机——立即打断，补充纠正。
- **收敛**：它是不是在原地打转？同一个词换了三种写法反复搜？该叫停就叫停。
- **源头**：交付物里引用的链接点开看看——它可能把营销软文当成了权威事实。

## 三、实操：搭一个"行业简报 Agent"

下面以 [[Dify]] / 扣子（Coze）这类无代码平台为例，搭一个能自主查资料、读网页、出简报的研究助理。全程不写代码。

### 1. 创建应用

平台里选 **Agent（智能体）模式**（不是普通对话应用），模型选推理能力第一梯队的（Claude 3.5 Sonnet、GPT-4o、DeepSeek-V3 级别）。

> [!question] 为什么聊天能用小模型，Agent 不行？
> 因为 Agent 要求模型：严格拼出不出错的工具调用 JSON、从报错里学会换策略、在十几轮中间结果里不忘初始目标。这些能力在纯聊天里根本考不到，但每一项都是 Agent 的生死线。

### 2. 挂两个工具

- **Web Search**：给它一双能上网的眼睛；
- **Web Scraper**（网页抓取）：让它能点开链接读正文，最好选带"HTML 转 Markdown"功能的——只喂正文，不喂几万字的页面代码，防止撑爆上下文。

### 3. 写系统提示词

直接复制这份起步模板，再按自己的领域改：

```markdown
你是一名行业情报分析 Agent，负责收集最新动态并整理成结构化简报。

工作流程：
1. 收到任务后，先拆解出 2～3 个核心信息点，再开始检索。
2. 用搜索工具找 3～5 篇权威报道；只对最有价值的 2 篇做正文抓取。
3. 每次调用工具后，用一句话说明拿到了什么、下一步做什么。
4. 事实数据（数字、日期、版本号）必须来自工具返回结果，
   禁止凭记忆填写。

停止条件：
- 搜索结果连续 2 次与目标无关 → 停止检索，向用户说明情况。
- 信息足够回答目标 → 立即停止调用工具，开始整理输出。

输出规范：
- 核心结论（300 字以内）
- Markdown 对比表格
- 参考来源清单（标题 + 链接 + 发布日期）
```

### 4. 设置运行参数

只改两处：

- **Temperature（随机性）调到 0.3 以下**——你要的是一个一丝不苟的会计，不是一个发挥灵感的诗人。随机性高的 Agent 会拼坏 JSON、乱选工具。
- **最大迭代轮数设 5～8 轮**——这是熔断保险丝，防死循环烧钱。

### 5. 跑一遍，逐项验收

输入测试任务：

> "调研本周大模型长上下文（Long Context）方向的重要更新，输出 3 条最重要的事件，附链接。"

对着检查单验收：

- [ ] 它是否**先说了搜索意图**、再调工具？（而不是闷头就搜）
- [ ] 抓到正文后是否做了**提炼**，而不是把几千字原文整段贴出来？
- [ ] 交付的 3 条事件是否**附带可点开的链接和日期**？
- [ ] 有没有在无关方向上反复搜索？（对照第 3 节的"收敛"）

四项全过，这个 Agent 才算能用。

## 四、进阶：缺工具找 MCP，缺章法写 Skill

跑通第一个 Agent 之后，两个需求会自然冒出来。

### 工具不够用 → 接 MCP

平台自带工具用腻了，想要更多？不用等平台开发——**MCP** 是行业统一的工具插口（「AI 应用的 USB-C」）：社区里已经有大查现成的 MCP Server（天气、RSS、数据库、浏览器自动化……），在 [[Dify]]、扣子里以「MCP」方式接入，配一次处处可用。协议细节见 [[MCP]]。

### 总在纠正同样的毛病 → 写 Skill

用几次你会发现，每次都在重复纠正同样的问题：「先列信息点再搜」「来源要标日期」。与其每次人肉纠正，不如把这些经验写成 **Skill**——一份「遇到 XX 任务照此办理」的操作手册，Agent 以后自己翻开照做。在无代码平台里它对应提示词模板 / 插件；在 Claude Code 这类客户端里，就是 skills 目录下一个带 SKILL.md 的文件夹。机制细节见 [[Skill]]。

> [!tip] 一句话记
> **缺工具找 MCP，缺章法写 Skill**。再加上喂事实的 [[RAG]]（见 [[构建RAG应用]]），三条路线各管一段：MCP 管「能干什么」，Skill 管「怎么干好」，RAG 管「依据是什么」。

## 五、常见坑

> [!warning] 三个高频事故及对策
> 1. **死循环**：搜索没结果，它换个近义词接着搜，循环到超时。
>    → 设最大轮数硬熔断 + 提示词写明"连续两次无结果就停下向我说明"。
> 2. **上下文爆炸**：抓回整页几万字的网页原文，工作台瞬间堆满，模型开始失忆。
>    → 用带正文抽取的工具（只喂正文不喂代码），或限制抓取篇数。
> 3. **盲信网页**：把营销软文、误报文章当权威事实直接加工。
>    → 提示词写"优先官方公告与权威媒体，来源冲突时标注存疑"；交付必须附链接，人工抽查。

## 六、安全底线：读写分离

一句话：**读操作可以全自动，写操作必须过人。**

搜索、读网页、做摘要——这些搞砸了顶多是浪费几轮预算，可以放手让它跑。

但发邮件、写入业务表格、下单支付这类动作，一旦做错**不可撤销**。这类工具必须配置**人工确认（Human-in-the-Loop）**：Agent 提出动作 → 系统挂起，等人点头 → 才真正执行。

无人值守的 Agent + 对外发送权限 = 迟早出事故。这条没有例外。
