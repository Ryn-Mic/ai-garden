# 练习材料与验收：先用虚构资料跑通一次

> [!info] 阅读定位
> **上手指南 · 入门**。不用编程，不用上传业务资料。用这套材料练习聊天、文件读取和 Skill，避免每篇教程都让你自己准备输入。

## 先下载练习包

**[[assets/examples/agent-practice.zip|下载通用 Agent 练习包 v1]]**。解压后打开 `agent-practice` 文件夹。

里面只有文字，没有脚本、宏、安装程序、密钥或网络服务。全部人物和记录是虚构的。

| 文件夹 | 内容 | 什么时候用 |
| --- | --- | --- |
| `materials` | 会议记录、每周工作记录 | 给 AI 的原始材料 |
| `expected` | 人工编写的验收清单 | 你自己检查结果，不当作原始材料先喂给 AI |
| `prompts` | 可以直接复制的工作说明 | 普通聊天或不支持 Skill 的软件 |
| `skills/weekly-summary` | 一份完整的 `SKILL.md` | 支持导入 Agent Skills 的应用 |

> [!note] 检查范围
> 本包的文字、文件结构和 Skill 格式已检查。验收清单是人工设计的标准，**不是某个产品的实测输出**；客户端加载和模型效果仍要在对应软件中验证。

## 练习 A：普通聊天，不安装任何东西

1. 新建聊天，复制 `prompts/weekly-summary.txt` 的工作说明。
2. 把 `materials/meeting.txt` 的全部文字一起粘贴。
3. 要求「请整理成行动清单」。
4. 用 `expected/meeting-check.txt` 逐项检查结果。

**成功标准**：小陈的截止日期是待确认；投放广告仍是讨论事项，不是已经安排的任务。

具体软件入口见 [[tutorials/software/WorkBuddy-Qoder-ChatGPT入门|WorkBuddy-Qoder-ChatGPT入门]]。如果没有解压工具，也可以分别打开 [[assets/examples/weekly-summary.txt|工作说明]] 和 [[assets/examples/meeting.txt|会议材料]] 复制文字。

## 练习 B：文件读取

1. 新建任务，只上传或引用 `materials/meeting.txt`。
2. 要求列出文件名、演示批次和会议事项的原文依据。
3. 检查应用的附件或读取记录，再核对结果。

**成功标准**：返回批次 `海风-7319` 且事实与文件一致。批次是辅助证据，不能仅凭答对编号就认定工具执行过。

先不要提供 `expected` 文件夹，以免把验收答案也当成待分析资料。资料读取问题见 [[concepts/AI能看到什么|AI能看到什么]]。

## 练习 C：周报或纯文字 Skill

1. 选择 `materials/weekly-work.txt`，不要把整个练习包当作任务资料。
2. 使用工作说明，或按 [[tutorials/skills/不写代码创建自己的Skill|不写代码创建自己的Skill]] 导入纯文字 Skill。
3. 输出周报，用 `expected/weekly-work-check.txt` 核对。

**成功标准**：客户问题「收集完成」与「分类未完成」分开；不能编造海报截止日期或预算金额。

只有确认本轮加载过 Skill，才能记录“加载已确认”。没有加载记录时，可以写“结果符合要求，加载未独立确认”。

## 怎样记录一次测试

```text
软件形态与版本：
输入材料：meeting.txt 或 weekly-work.txt
提供方式：粘贴 / 附件 / 文件引用
是否加载 Skill：已确认 / 未使用 / 无法独立确认
通过的验收项：
失败的验收项：
实际产生的文件或动作：
```

先保留失败样例，再修改要求。多次通过说明这个练习更稳定，不代表在所有任务、版本和材料上都可靠。
