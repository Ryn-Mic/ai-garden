# 系列阅读

**这里负责“先读什么、后读什么”，不重复存放文章正文。**

第一次使用 AI，先选系列 01。每条系列的编号是阅读顺序，不代表所有系列都必须完成。

## 研究路线：两条独立的技术选修

- **[[series/04-Agent机制与可靠性|04 · Agent 机制与可靠性]]**：关注应用怎样组织信息与调用工具；需要技术背景。
- **[[series/05-模型与RAG基础|05 · 模型与 RAG 基础]]**：关注模型与检索原理；架构深入和开发实验有各自前提。

不用先装 MCP 才能研究模型，也不用先读 Transformer 才能做文字整理。

## 每条系列怎样读

1. 沿主线的 `1 → 2 → 3` 前进，一次只完成当前站。
2. 遇到“中途补课”，跳到对应独立知识点，理解后回到本系列。
3. 对照这一站的完成标准，再进入下一站。

**中途补课**解决当前任务的疑问；**选读**不影响主线；**选做**需要额外条件，不算默认必修。正文末尾也提供返回系列和下一站的入口。
